Conclusiones e importancia

El desarrollo de este proyecto permitió aplicar de forma práctica conocimientos de electrónica, programación y desarrollo web.

Conclusiones

  • Aprendizaje

    El proyecto permitió reforzar de manera práctica los conocimientos teóricos adquiridos en clase sobre electrónica y programación.

  • Arduino

    Se comprendió el funcionamiento de Arduino como plataforma de control, capaz de procesar información y comunicarse con otros componentes electrónicos.

  • Pantalla LCD

    Se aprendió a controlar una pantalla LCD desde Arduino, ajustando su contraste con un potenciómetro y mostrando información de forma clara.

  • Conexiones

    El armado del circuito permitió afianzar la correcta identificación de polaridades, pines y el uso adecuado de una protoboard.

  • Programación

    Se desarrollaron habilidades para escribir, depurar y cargar código en Arduino IDE, controlando la salida de información hacia la pantalla LCD.

  • Sitio web

    La creación del sitio permitió aplicar HTML5, CSS3 y JavaScript para comunicar de forma clara y ordenada el trabajo realizado.

Importancia del proyecto

Desarrollar el circuito de control y visualización con Arduino tiene un valor significativo dentro de la formación técnica, ya que combina electrónica, programación y diseño de interfaces en un mismo proyecto orientado a la salud.

Este tipo de trabajo acerca a los estudiantes a problemas reales, como mostrar información de forma clara para el usuario, y fomenta la capacidad de diseñar soluciones tecnológicas útiles, sencillas y de bajo costo, sentando una base sólida para incorporar en el futuro un sensor real de frecuencia cardíaca y proyectos más complejos en el área de la informática y la electrónica.

Reflexión final

Creatividad e innovación

Este proyecto refleja cómo la creatividad puede transformar conocimientos técnicos en una solución concreta y funcional. Combinar una placa programable con una pantalla de visualización no solo enseña electrónica, sino que despierta la capacidad de imaginar nuevas aplicaciones para la tecnología.

Arduino, la electrónica, la programación y el desarrollo web se integraron en un solo proyecto, demostrando que es posible transformar el aprendizaje del aula en una propuesta tecnológica y educativa con impacto real.
