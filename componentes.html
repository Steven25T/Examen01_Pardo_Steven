Componentes

Estos son los elementos electrónicos utilizados para construir el circuito, tal como aparecen conectados en el diagrama de Tinkercad. Cada tarjeta incluye un espacio para la fotografía real del componente.

Arduino UNO Pantalla LCD 16x2 Protoboard Potenciómetro Resistencia Cables Dupont Cable USB
Placa de control

Arduino UNO

Definición

Placa de desarrollo con un microcontrolador programable, utilizada para leer sensores y controlar dispositivos electrónicos.

Función

Recibe y procesa la información del circuito, y controla lo que se muestra en la pantalla LCD.

Salida de datos

Pantalla LCD 16x2

Definición

Pantalla de cristal líquido con 16 columnas y 2 filas, utilizada para mostrar texto e información numérica en tiempo real.

Función

Mostrar en pantalla la información calculada por el Arduino, así como los mensajes del sistema.

Montaje

Protoboard

Definición

Tablero de conexiones sin soldadura que permite armar circuitos electrónicos de forma temporal y ordenada.

Función

Servir de base para conectar la pantalla LCD, el potenciómetro, la resistencia y los cables del circuito.

Ajuste

Potenciómetro

Definición

Resistencia variable que se ajusta manualmente girando una perilla, cambiando así el valor eléctrico que entrega al circuito.

Función

Ajustar el contraste de la pantalla LCD para lograr una correcta visualización de los datos.

Regulación

Resistencia

Definición

Componente electrónico que limita el paso de corriente eléctrica dentro de un circuito.

Función

Limitar la corriente que llega a la pantalla LCD, protegiendo el circuito de posibles daños.

Conexión

Cables Dupont

Definición

Cables con conectores macho y hembra utilizados para unir componentes electrónicos sin necesidad de soldadura.

Función

Transmitir la señal y la alimentación eléctrica entre la protoboard y el Arduino.

Alimentación

Cable USB

Definición

Cable utilizado para conectar el Arduino al computador.

Función

Alimentar la placa y transferir el programa desarrollado hacia el Arduino.
